## 1. 一句话与主题

一句话：一个新人进入“远望交易学院”，从给自己下单，到替客户管理资金，最后必须在一场系统性危机中证明：**活下来，比赚得快更重要。**

主题：
- 交易的第一课不是赚钱，而是承认自己会错。
- 从“对自己负责”到“对别人的钱负责”，是职业和业余的分界线。
- 杠杆、做空、期权、期货都不是坏东西；坏的是不知道自己为什么用、最坏会怎样。
- 风险控制不是懦弱，而是让下一笔交易还有机会发生。

基调：金融职场成长 + 轻悬疑 + 师徒关系。不要写成爽文，不要神化主角，不要承诺收益。

## 2. 世界观与时间线

- 远望交易学院（Farview Trading Academy）：表面是金融教育学院，实际也管理一支小型模拟基金“远望一期”。
- 学院使用虚构市场：50 家公司、4 只 ETF、确定性模拟行情；所有公司、价格、新闻均为教学用途。
- 学生账户初始 10 万美元；市场 09:30 开盘、16:00 收盘；课程按 Unit 1–32 逐步解锁。
- 远望一期基金：学院年度考核项目，由职业等级达到组合经理的学员负责。客户是学院邀请的模拟客户。
- 时间线：一个学年，约 60–120 个交易日；具体以 Unit 完成和职业等级推进，不强制固定天数。
- 三条职业底线：
  1. 不向客户承诺收益。
  2. 不隐瞒风险。
  3. 不用客户的钱证明自己的聪明。

## 3. 角色

### 主角（可自定义姓名）
- 身份：远望交易学院新学员。
- 初始欲望：证明自己能在市场里赚钱。
- 真正需要：学会对风险、对客户、对自己的判断负责。
- 弧光：从“想赢”到“想活得久”，从“交易员”到“掌舵人”。

### 林岚（Lin Lan）· 首席导师
- 表面：冷静、克制、说话像风控报告。
- 前史：曾任“远望旧基金”基金经理，在一次系统性危机中清盘。外界认为她判断失误，她从不解释。
- 真相：她不是没看懂危机，而是在最后时刻选择优先兑付客户赎回，放弃了翻本机会；她输给了“不肯认错”，也赢回了底线。
- 口头禅：“市场不会因为你努力就奖励你。它只会在你做错时收学费。”
- 弧光：从背着旧事教书，到把“承认错误”的方法交给主角，最终与过去和解。

### 顾言（Gu Yan）· 明星学员 / 镜像对手
- 表面：天赋高、反应快、敢上杠杆，短期业绩总是第一。
- 信念：回撤是别人的事，收益是我的事。
- 作用：不是反派，而是主角的另一种可能。他可成为盟友，也可能成为警告。
- 弧光：如果主角坚持风控，他会在危机中爆仓；如果主角多次选择激进，他会成为主角未来的影子。

### 苏禾（Su He）· 风控与合规官
- 表面：不受欢迎的“踩刹车的人”。
- 信念：你可以不同意风控，但你不能绕过它。
- 作用：在保证金、回撤、客户赎回、基金清盘线上制造真实压力；也是主角最重要的盟友之一。

### 周衡（Zhou Heng）· 宏观教授
- 表面：讲课慢、爱讲历史。
- 信念：危机不是黑天鹅，是被忽略的灰犀牛。
- 作用：在利率、通胀、经济周期和危机前夜提供线索，但从不预言具体点位。

### 陈曦（Chen Xi）· 量化研究员
- 表面：相信数据、讨厌故事。
- 信念：数据不会说谎，但会过拟合。
- 作用：提供回测、因子、组合优化和“样本外”视角；提醒主角不要用历史证明未来。

### 王先生（Mr. Wang）· 第一位基金客户
- 身份：退休教师，模拟客户，风险承受能力低。
- 诉求：“我不懂期权，我只想知道最坏会亏多少。”
- 作用：客户信任的具象化。主角每一次激进选择，都会在他身上产生后果。

### 老陈（Lao Chen）· 做市商 / 交易大厅前辈（可选）
- 作用：订单簿、流动性、滑点章节的引路人。
- 台词：“盘口不会骗你，但会试探你。”

## 4. 四幕结构

| 幕 | 章节 | 对应系统 | 核心问题 |
|---|---|---|---|
| 第一幕：学徒 | 1–5 | u1–u8，基础交易、股息、ETF | 我为什么要交易？ |
| 第二幕：分析师 | 6–9 | u9–u18，财报、估值、宏观、做空、保证金 | 我的判断值多少钱？ |
| 第三幕：交易员 | 10–12 | u21–u28，期权、收入策略、客户与基金 | 我能不能对别人的钱负责？ |
| 第四幕：掌舵人 | 13–15 | u29–u32，期货、对冲、系统性风险、毕业 | 危机来了，我守什么？ |

## 5. 章节细纲

### 第 1 章：入职第一天
- 触发：`game_new`
- 场景：远望交易学院大厅 → 交易大厅 → 工位。
- 节拍：
  1. 林岚带主角熟悉行情、交易台、持仓三个区域。
  2. 林岚给出第一家公司，让主角选择先看财报还是先看走势。
  3. 顾言路过，留下一句“学院教的是不亏钱，市场奖励的是敢下注”。
- 选择：
  - 先读财报和估值 → `path = value`
  - 先看价格和成交量 → `path = momentum`
- 教学点：股票是什么、账户结构、交易时间。
- 关键台词：林岚：“先别急着下单。今天你只需要弄明白，你买的到底是什么。”

### 第 2 章：第一笔成交
- 触发：首次 `trade_filled`
- 场景：工位，成交回报弹出。
- 节拍：
  1. 林岚要求主角写下买入理由、退出条件、最大可接受亏损。
  2. 顾言晒出更快的短线收益，暗示主角“太慢”。
  3. 主角第一次复盘：成本、仓位、滑点。
- 选择：
  - 写交易日志 → `discipline = true`
  - 先看下一笔机会 → `discipline = false`
- 教学点：成本基础、持仓占比、订单类型、成交规则。
- 关键台词：林岚：“成交不是结束，是复盘开始的地方。”

### 第 3 章：第一天收盘
- 触发：`day_closed` 且 `day >= 1`
- 场景：收盘后的交易大厅。
- 节拍：
  1. 林岚给出目标：权益达到 10.3 万，同时保留至少 40% 现金。
  2. 顾言认为目标太保守，展示自己的满仓收益。
  3. 第二天核对目标；完成或未完成都有不同反馈。
- 选择：
  - 接受风险优先 → `mission_day1 = accepted`
  - 拒绝，按自己的节奏 → `mission_day1 = declined`
- 教学点：盈亏、现金、仓位管理。
- 关键台词：林岚：“仓位管理才是职业和业余的分界线。”

### 第 4 章：第一笔股息
- 触发：首次股息 / Unit 5 完成
- 场景：股息入账通知；学院咖啡角。
- 节拍：
  1. 主角发现没有卖出也收到了现金。
  2. 林岚解释股息、除息、现金流和再投资。
  3. 顾言说股息“太慢”，主角要决定是否把股息再投入。
- 选择：
  - 再投资 → `income_style = reinvest`
  - 留作现金 → `income_style = cash`
- 教学点：股息、复利、现金流。
- 关键台词：林岚：“市场里最快的钱，通常也最快离开。”

### 第 5 章：篮子与分散
- 触发：Unit 7 完成 / 首次 ETF 交易
- 场景：ETF 交易台；顾言押注单只股票。
- 节拍：
  1. 主角第一次看到 ETF 的成分、权重、费率。
  2. 顾言嘲笑“买一篮子等于承认自己不知道选哪只”。
  3. 市场出现单只股票暴雷，主角的分散组合回撤更小。
- 选择：
  - 用 ETF 做核心配置 → `diversify = etf`
  - 集中持有看好的公司 → `diversify = single`
- 教学点：ETF、分散、费用率、篮子净值。
- 关键台词：苏禾：“分散不是没有风险，是不要让一个错误决定你整年的业绩。”

### 第 6 章：第一份研究报告
- 触发：Unit 11 或 12 完成 / 查看两家公司财报
- 场景：研究区；深夜的灯。
- 节拍：
  1. 主角选择一个虚构公司，读三张报表。
  2. 林岚要求给出估值区间，而不是一个精确目标价。
  3. 顾言只看价格，认为报告“写给客户看”。
- 选择：
  - 用 DCF / 倍数做估值 → `research = valuation`
  - 用趋势和相对强弱 → `research = trend`
- 教学点：财报、估值、安全边际。
- 关键台词：林岚：“财报是过去，价格是预期。你的工作是找出差距。”

### 第 7 章：利率冲击
- 触发：Unit 13 完成 + 宏观事件日
- 场景：宏观课；行情屏突然转红。
- 节拍：
  1. 周衡讲利率、通胀、折现率，以及“估值最怕什么”。
  2. 组合出现回撤；顾言加仓，苏禾要求降低风险。
  3. 主角决定减仓、对冲还是硬扛。
- 选择：
  - 降低仓位 → `risk_response = cut`
  - 用期货/现金对冲 → `risk_response = hedge`
  - 继续持有 → `risk_response = hold`
- 教学点：利率、通胀、宏观传导、组合风险。
- 关键台词：周衡：“危机不是黑天鹅，是没人愿意看的灰犀牛。”

### 第 8 章：做空的镜子
- 触发：首次做空 / Unit 17 完成
- 场景：研究会议室；一家公司的财务疑点。
- 节拍：
  1. 主角发现应收、存货或现金流异常。
  2. 可以选择做空，或把问题写进研究报告。
  3. 顾言选择重仓做空，林岚提醒借券成本和无限亏损。
- 选择：
  - 做空 → `ethics = short`
  - 写报告、不交易 → `ethics = report`
- 教学点：做空、借券、保证金、无限风险。
- 关键台词：林岚：“做空能赚钱，但也会放大你的傲慢。”

### 第 9 章：杠杆之夜
- 触发：首次融资 / `margin_call`
- 场景：夜盘；追加保证金通知。
- 节拍：
  1. 顾言的杠杆组合大赚，主角的账户收到保证金警报。
  2. 林岚第一次提到自己的旧基金，但没有解释细节。
  3. 主角决定减仓、补保证金还是继续扛。
- 选择：
  - 主动降杠杆 → `leverage = reduce`
  - 补保证金继续持有 → `leverage = add`
  - 硬扛 → `leverage = hold`
- 教学点：保证金、维持担保比例、强制平仓。
- 关键台词：苏禾：“市场不会给你体面退出的机会，除非你提前留好现金。”

### 第 10 章：期权到期日
- 触发：首次期权交易 / Unit 21 或 25 完成
- 场景：期权交易台；到期日倒计时。
- 节拍：
  1. 主角学习权利金、行权价、到期日和 Greeks。
  2. 顾言买入虚值期权赌方向；主角可以选择卖出 Covered Call 收租。
  3. 到期日出现指派或归零，两种结果都给出反馈。
- 选择：
  - 卖出有担保期权 → `option_style = covered`
  - 买入方向性期权 → `option_style = speculate`
- 教学点：期权定价、Greeks、卖方风险、指派。
- 关键台词：林岚：“期权不是彩票。它是一份把风险和收益拆开的合约。”

### 第 11 章：客户的信任
- 触发：职业等级 5 / 创建基金
- 场景：远望一期基金成立；客户会议。
- 节拍：
  1. 王先生成为第一位客户，只问“最坏会亏多少”。
  2. 主角选择费率、业绩门槛和风险说明。
  3. 顾言建议用高收益吸引客户，苏禾要求写清风险。
- 选择：
  - 透明说明风险 → `client_trust = high`
  - 强调收益、弱化风险 → `client_trust = low`
- 教学点：基金、管理费、业绩报酬、高水位、客户预期。
- 关键台词：王先生：“我不懂你们的产品，我只想知道，最坏的时候我还能剩下多少。”

### 第 12 章：危机前夜
- 触发：Unit 29 完成 / 首次期货交易
- 场景：宏观研判会；风暴前的平静。
- 节拍：
  1. 周衡给出多个预警信号，但没有人知道危机会不会来。
  2. 主角决定用股指期货对冲多少仓位。
  3. 顾言选择继续加杠杆，认为“这次不一样”。
- 选择：
  - 充分对冲 → `hedge = full`
  - 部分对冲 → `hedge = partial`
  - 不对冲 → `hedge = none`
- 教学点：期货、保证金、对冲比率、系统性风险。
- 关键台词：林岚：“对冲不是预测危机，是让你在危机里还能做选择。”

### 第 13 章：黑色星期五
- 触发：大幅回撤 / `margin_call` / 特定危机日
- 场景：交易大厅；红色行情；客户电话不断。
- 节拍：
  1. 市场跳空，顾言的杠杆组合爆仓，客户开始赎回。
  2. 王先生打电话问：“你不是说最坏只有 10% 吗？”
  3. 主角必须决定：保客户、保基金、还是保自己的业绩。
- 选择：
  - 优先兑付客户、降低风险 → `crisis_choice = protect`
  - 继续加仓博反弹 → `crisis_choice = attack`
  - 暂停赎回、等待流动性 → `crisis_choice = gate`
- 教学点：流动性、回撤、赎回、基金清盘线。
- 关键台词：林岚：“你现在管的不是一笔交易，是别人的人生。”

### 第 14 章：毕业答辩
- 触发：Unit 32 完成 / 毕业挑战
- 场景：答辩教室；林岚、苏禾、周衡、王先生在场。
- 节拍：
  1. 主角陈述投资框架、风险预算、危机复盘。
  2. 林岚揭开旧基金清盘的真相：她选择兑付客户，而不是翻本。
  3. 主角选择自己的职业方向。
- 选择：
  - 继续管理基金 → `ending_path = manager`
  - 回到学院教书 → `ending_path = mentor`
  - 加入顾言式的高风险团队 → `ending_path = star`
- 教学点：综合复盘、职业伦理、长期主义。
- 关键台词：林岚：“那年我不是输给市场，我是输给了不肯认错。”

### 第 15 章：尾声
- 根据旗标播放不同结局，不设“完美结局”，只设“你愿意承担的结果”。

### 结局
- **稳健掌舵人**：`client_trust=high`、`crisis_choice=protect`、基金存活。王先生继续持有；林岚成为合伙人。
- **明星交易员**：收益高、回撤高、`crisis_choice=attack`。客户变多但信任脆弱；顾言成为同事或镜像。
- **学院导师**：`ending_path=mentor`、课程完成度高。主角回到远望教书，林岚退休。
- **清盘复盘**：高杠杆 + `crisis_choice=attack/gate` + 客户信任低。基金清盘，主角在空办公室复盘，重新开始。

## 7. 支线与日常事件

- **课程支线**：每完成一个 Unit，触发一条 2–4 节点的短对话，由林岚、苏禾或周衡点评。
- **职业支线**：晋升时触发 1 段职业对话；研究任务、投资报告、绩效评价各有独立反馈。
- **客户支线**：王先生的电话/邮件，随基金回撤和收益变化；可以安排一次赎回危机。
- **量化支线**：陈曦提醒回测过拟合；主角可以选择相信模型还是相信常识。
- **税务支线**：第一次卖出盈利后，苏禾解释税费和记录；对应税务实验室。
- **历史实验室支线**：周衡带主角复盘 2008/2020/2022，强调幸存者偏差和真实数据边界。
- **挑战支线**：完成/失败挑战时，顾言或林岚给出短评，不改变主线。

## 10. 写作规范

- 每章 4–8 个节点，1–2 个关键选择；总文本控制在 600–1000 字（中文）。
- 台词短、专业、克制；避免网络梗、喊口号、长篇说教。
- 每个选择都要有代价，不要“明显正确”和“明显错误”。
- 不用真实公司内幕、真实人物、保证收益、鼓励赌博。
- 金融概念必须准确；不确定时用“教学近似”并让角色说明边界。
- 中英双语；英文避免直译中文成语，保留角色语气。

## 11. 给 Gemini 的优化提示

请保留：
- 章节顺序、触发条件、旗标名、结局条件、与 Unit/职业/基金/期权/期货的映射。
- 每章的教学点和关键选择。
- 林岚、顾言、苏禾、周衡、陈曦、王先生的人物功能。

可以优化：
- 台词、场景细节、节奏、章节标题、人物前史。
- 增加 1–2 个日常支线，但不要影响主线解锁。
- 把每章拆成可执行的 JSON 节点，输出格式：
  - `id`、`title`、`start`、`nodes`
  - 节点类型：`line` / `choice` / `end`
  - `speaker`、`text` 使用 `{ "zh_CN": "...", "en": "..." }`
  - 选项包含 `text`、`next`、`effects`
  - 需要新增条件/效果时，在 JSON 外用注释标明，不要静默改游戏机制。

不要加入：
- 真实公司内幕、真实人物、收益承诺、投资建议。
- 与模拟交易规则冲突的剧情（例如没有期权系统时让角色交易期权）。
- 过度戏剧化的三角恋、商战阴谋、违法操作教程。
